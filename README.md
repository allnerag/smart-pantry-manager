# Smart Pantry Manager

Smart Pantry Manager is a Java Android application being developed for the Mobile App Development 700 assignment. It aims to reduce food waste by suggesting recipes using ingredients already available at home.
This version is local only, once you downloaded you do not require to connect to the internet to use it. Everything is in your hands.



## Project status

Deployed working version.

## 

## Current Features

* Add, view, edit and delete pantry ingredients.
* Save ingredient names, quantities and units.
* Include 20 recipes with ingredients and preparation steps.
* Suggest a recipe only when every required ingredient is available in a sufficient quantity.
* Handle common ingredient names and compatible units.
* Save pantry data and basic settings between app sessions.
* Removed check against water and salt requirements.
* Included a section to add your own recipes with ingredients and preparation steps.



## Future Features

* Automatically update ingredients after completed with recipes.
* Be able to swap sauces and non critical ingredients



## Technology

* Android Studio
* Java with XML layouts
* SQLite using SQLiteOpenHelper
* ListView with custom adapters
* SharedPreferences for settings



## Database usage

* SQLite is used for local only, like a free version. You manage your own recipes.
* PosGreSQL will be used for paid version where we will updated and add recipes.
